\# Appointment Management System



A prototype appointment and customer management system for small businesses.



\## Technologies

\- ASP.NET Core Web API

\- Entity Framework Core

\- SQL Server / LocalDB

\- React + Vite



\## Project Structure

\- `backend/` -> ASP.NET Core API

\- `frontend/` -> React frontend



\## Run Backend

Open the backend project in Visual Studio and run it.



\## Run Frontend

```bash

npm install

npm run dev

\## Requirements

.NET SDK

Node.js

SQL Server Express / LocalDB
